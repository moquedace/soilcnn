# Print a fold plan, with its per-fold sizes.

Print a fold plan, with its per-fold sizes.

## Usage

``` r
# S3 method for class 'fold_plan'
print(x, ...)
```

## Arguments

- x:

  A `fold_plan`, from
  [`resolve_resampling()`](https://moquedace.github.io/soilcnn/reference/resolve_resampling.md)
  or a fold constructor.

- ...:

  Ignored.

## Value

`x`, invisibly.
