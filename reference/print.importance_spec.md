# Print an importance method.

Print an importance method.

## Usage

``` r
# S3 method for class 'importance_spec'
print(x, ...)
```

## Arguments

- x:

  An `importance_spec`, from
  [`permutation_importance()`](https://moquedace.github.io/soilcnn/reference/permutation_importance.md).

- ...:

  Ignored.

## Value

`x`, invisibly.
