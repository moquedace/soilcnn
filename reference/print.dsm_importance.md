# Print a variable importance.

Print a variable importance.

## Usage

``` r
# S3 method for class 'dsm_importance'
print(x, n = 20L, ...)
```

## Arguments

- x:

  A `dsm_importance`, from
  [`dsm_importance()`](https://moquedace.github.io/soilcnn/reference/dsm_importance.md).

- n:

  How many variables to show.

- ...:

  Ignored.

## Value

`x`, invisibly.
