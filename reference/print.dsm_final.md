Print a `dsm_final`

## Usage

``` r
# S3 method for class 'dsm_final'
print(x, ...)
```

## Arguments

  A `dsm_final`, from
  [`dsm_final()`](https://moquedace.github.io/soilcnn/reference/dsm_final.md)

  [`dsm_report_final()`](https://moquedace.github.io/soilcnn/reference/dsm_report_final.md).

- ...:

  Ignored.

## Value
