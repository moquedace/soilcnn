# Say what the occlusion found, including when it found nothing.

Say what the occlusion found, including when it found nothing.

## Usage

``` r
# S3 method for class 'spatial_occlusion'
print(x, ...)
```

## Arguments

- x:

  A `spatial_occlusion`, from
  [`occlusion_report()`](https://moquedace.github.io/soilcnn/reference/occlusion_report.md).

- ...:

  Ignored.

## Value

`x`, invisibly.
